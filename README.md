# Тестовое задание: UI мессенджера на Vue 3

**Запуск**

```bash
npm install
npm run dev
```

Приложение: [http://localhost:5173](http://localhost:5173)  
Fake API: `http://127.0.0.1:3000` (проксируется через `/api`)

**Сборка** (`npm run build`) не поднимает fake API — для проверки UI используйте `npm run dev`.

**Авторизация**
Верные данные - user / password
Любые другие данные - 401 и сообщение об ошибке в форме.

**Проверка ошибок отправки**

В любом чате отправьте текст:
```text
fail
```

**Отличия от ТЗ**

Чаты подгружаются по 10, сообщения по 20 (меньше тестовых данных);
Длинную историю сообщений удобнее смотреть в первых двух чатах.
