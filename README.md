# Тестовое задание: UI чата

Запуск npm install -> npm run dev
Сборка npm run build (для продакшена требуется развернуть полноценное api)
Тестирование npm run test

**Для авторизации использовать user / password**

Изменения по сравнению с ТЗ:

- подгружаются 10 чатов за раз (из-за общего количества данных)
- подгрузку сообщений можно проверить в первых двух чатах

**Для имитации ошибки в чате - отправить fail**
